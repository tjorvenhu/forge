# Bundled third-party software

The Windows installer of FORGE contains the following programs unchanged (except for removed documentation and
translations in Git). The license texts are in the installation under `runtime/`. The macOS and Linux builds
(`.dmg`, `.app.tar.gz`, `.AppImage`, `.deb`) contain only Node.js (the complete official folder with npm and
corepack, `runtime/node/LICENSE`) and the GitHub CLI (without man pages); Git and Python come from the system there.

| Software | Version | License | Source |
|---|---|---|---|
| Node.js | 24.21.0 | MIT (and others, see `runtime/node/LICENSE`) | https://nodejs.org |
| Git for Windows (PortableGit) | 2.56.0.2 | GPL-2.0 and others, see `runtime/git/LICENSE.txt` | https://gitforwindows.org |
| GitHub CLI | 2.102.0 | MIT (`runtime/gh/LICENSE`) | https://cli.github.com |
| Python (NuGet package `python`, with pip) | 3.14.8 | PSF License and others, see `runtime/python/LICENSE.txt` | https://www.python.org |

Source code of Git for Windows: https://github.com/git-for-windows/git/releases/tag/v2.56.0.windows.2
(GPL-2.0: the source code of the bundled version is available there).

Not in the installer, but downloaded when a test database is started for the first time: PostgreSQL 17.10 for
Windows x64 (PostgreSQL License, https://www.postgresql.org/about/licence/) from the npm package
`@embedded-postgres/windows-x64` (MIT, https://github.com/leinelissen/embedded-postgres). It contains libraries
such as OpenSSL, ICU, zlib and libxml2 under their own licenses. Location: `%APPDATA%/forge/postgres`.

The npm packages bundled in FORGE (among them React, Radix UI, TanStack, Zod, Claude Agent SDK, the fonts Geist
and Geist Mono under the SIL Open Font License 1.1) are listed with license, copyright notice and license text in
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). The file is generated by `pnpm notices`
(`scripts/third-party-notices.mjs`); regenerate and commit it after changing dependencies.

Both files are also in the FORGE installation folder, together with `LICENSE.md` and `NOTICE`.

## Deutsch: Mitgelieferte Software von Drittanbietern

Der Windows-Installer von FORGE enthält folgende Programme unverändert (bis auf entfernte
Dokumentation und Übersetzungen bei Git). Die Lizenztexte liegen in der Installation unter `runtime/`. Die Builds
für macOS und Linux (`.dmg`, `.app.tar.gz`, `.AppImage`, `.deb`) enthalten nur Node.js (den ganzen offiziellen
Ordner mit npm und corepack, `runtime/node/LICENSE`) und die GitHub CLI (ohne Manpages). Git und Python kommen
dort vom System.

| Software | Version | Lizenz | Quelle |
|---|---|---|---|
| Node.js | 24.21.0 | MIT (und weitere, siehe `runtime/node/LICENSE`) | https://nodejs.org |
| Git for Windows (PortableGit) | 2.56.0.2 | GPL-2.0 und weitere, siehe `runtime/git/LICENSE.txt` | https://gitforwindows.org |
| GitHub CLI | 2.102.0 | MIT (`runtime/gh/LICENSE`) | https://cli.github.com |
| Python (NuGet-Paket `python`, mit pip) | 3.14.8 | PSF License und weitere, siehe `runtime/python/LICENSE.txt` | https://www.python.org |

Quellcode von Git for Windows: https://github.com/git-for-windows/git/releases/tag/v2.56.0.windows.2
(GPL-2.0: der Quellcode der mitgelieferten Version ist dort erhältlich).

Nicht im Installer, sondern beim ersten Start einer Test-Datenbank geladen: PostgreSQL 17.10 für Windows x64
(PostgreSQL License, https://www.postgresql.org/about/licence/) aus dem npm-Paket `@embedded-postgres/windows-x64`
(MIT, https://github.com/leinelissen/embedded-postgres). Es enthält Bibliotheken wie OpenSSL, ICU, zlib und libxml2
unter ihren eigenen Lizenzen. Ablage: `%APPDATA%/forge/postgres`.

Die in FORGE gebündelten npm-Pakete (u. a. React, Radix UI, TanStack, Zod, Claude Agent SDK, die Schriften Geist
und Geist Mono unter der SIL Open Font License 1.1) stehen mit Lizenz, Copyright-Hinweis und Lizenztext in
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Die Datei erzeugt `pnpm notices` (`scripts/third-party-notices.mjs`);
nach Änderungen an den Abhängigkeiten neu erzeugen und einchecken.

Beide Dateien liegen zusammen mit `LICENSE.md` und `NOTICE` auch im Installationsordner von FORGE.
